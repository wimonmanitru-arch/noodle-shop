# เส้นสุข Noodle House — เว็บไซต์ขายบะหมี่กึ่งสำเร็จรูป

เว็บไซต์ตัวอย่างสำหรับโครงงาน E-commerce มีสินค้า 2 SKUs, ตะกร้าสินค้า, แบบฟอร์มสั่งซื้อ, การเตรียมใบจ่าหน้าพัสดุ และการเชื่อมต่อ Google Sheets ผ่าน Google Apps Script

## โครงสร้าง
- `index.html` หน้าเว็บไซต์
- `style.css` รูปแบบและการแสดงผลแบบ Responsive
- `script.js` สินค้า ตะกร้า คำสั่งซื้อ และใบจ่าหน้าพัสดุ
- `images/` โฟลเดอร์สำหรับเก็บรูปสินค้า (ใส่รูปจริงเพิ่มเติมได้)
- `google-apps-script/Code.gs` โค้ดรับคำสั่งซื้อและบันทึกลง Google Sheets

## วิธีเชื่อม Google Sheets
1. สร้าง Google Sheets ใหม่ ตั้งชื่อไฟล์ `Noodle Shop Orders`
2. เปิด Extensions > Apps Script
3. คัดลอกโค้ดจาก `google-apps-script/Code.gs` ไปวาง แล้วกด Save
4. กด Deploy > New deployment > เลือกประเภท Web app
5. Execute as: Me และ Who has access: Anyone (ลิงก์นี้เป็นจุดรับข้อมูลสาธารณะ ห้ามใส่ข้อมูลลับ)
6. กด Deploy และคัดลอก Web app URL ที่ลงท้าย `/exec`
7. เปิด `script.js` แล้วใส่ URL ใน `GOOGLE_SHEETS_WEB_APP_URL`
8. บันทึกไฟล์และอัปโหลดขึ้น GitHub ใหม่

> หมายเหตุ: ตัวอย่างใช้ `fetch` แบบ `no-cors` เพื่อส่งข้อมูลจากหน้าเว็บ จึงอ่านผลตอบกลับจาก Google ไม่ได้ หน้าเว็บจะแจ้งว่าจัดส่งคำขอแล้ว แต่ควรตรวจสอบว่ามีแถวใหม่ในชีตจริงก่อนใช้งาน/สาธิต

## วิธีใช้งานระบบ
1. เปิดเว็บไซต์ เลือกสินค้าและเพิ่มลงตะกร้า
2. กรอกชื่อ เบอร์โทร และที่อยู่ให้ครบ แล้วกดยืนยันคำสั่งซื้อ
3. ระบบสร้างใบจ่าหน้าพัสดุในแท็บใหม่ กดพิมพ์หรือบันทึกเป็น PDF
4. ใช้ข้อมูลในชีตเป็นรายการหยิบสินค้า ตรวจ SKU และจำนวนให้ตรงก่อนแพ็ค
5. เปลี่ยนสถานะคำสั่งซื้อในชีตตามขั้นตอน เช่น รอหยิบสินค้า / กำลังแพ็ค / พร้อมจัดส่ง / จัดส่งแล้ว

## อัปโหลด GitHub
1. เข้า GitHub แล้วสร้าง New repository เช่น `noodle-shop`
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดใน ZIP นี้ (แตก ZIP ก่อน)
3. กด Commit changes

## Deploy บน Vercel
1. เข้า https://vercel.com แล้ว Sign up / Log in
2. เลือก Add New > Project
3. Import Git Repository `noodle-shop`
4. Framework Preset เลือก Other และ Build Command / Output Directory เว้นว่าง (Static HTML)
5. กด Deploy แล้วเปิดโดเมน `.vercel.app` ที่ระบบสร้างให้

## ข้อควรทราบ
- เป็นระบบตัวอย่างสำหรับการเรียน ไม่มีระบบตัดบัตร/ชำระเงินออนไลน์
- ใบจ่าหน้าเป็นเอกสารข้อมูลผู้รับสำหรับสาธิต ไม่ใช่ใบปะหน้าที่ออกจากระบบขนส่งจริง และไม่มีเลข Tracking
- ก่อนส่งงานให้ทดลองสั่งซื้อ ตรวจ Google Sheets และทดลองพิมพ์ใบจ่าหน้าหนึ่งครั้ง
- เปลี่ยนชื่อร้าน รายการสินค้า ราคา และรูปภาพให้ตรงกับโจทย์หรือความต้องการของกลุ่มได้
